# پنل مدیریت سودو — اونیکس

**ورود:** `/sudo` در بات (فقط آیدیهای `SUDO_IDS`) → دکمه WebApp تب «مدیریت».

## قابلیت‌ها

| بخش | کار |
|-----|-----|
| نمای کلی | شمارنده‌ها: کاربر، سکه، شارژ، گزارش، اسپانسر، قفل گروه |
| کاربر / جادو | جستجو، اعطای سکه ±، انتقال جادو/آیتم شاپ بدون درگاه، برگشت لجر |
| شارژ | سفارش manual (قبل از درگاه)؛ fix به paid/failed/reversed |
| لجر | لیست سراسری + reverse برای تعمیر تراکنش خراب |
| اسپانسر | افزودن/خاموش کردن اسپانسر |
| قفل گروه | `sponsor_lock` روی گروه — فقط اسپانسر فعال یا سودو start می‌زند |
| گزارش / بن / چالش | moderation و بستن چالش |
| تنظیمات | `charge_live`، اعطای دستی، قفل پیش‌فرض |

## قرارداد درگاه

1. تا `charge_live=false`: سودو با manual grant سکه/جادو می‌دهد.  
2. بعد از تأیید بانک: `charge_live=true` → پرداخت خودکار؛ نقش سودو = تعمیر سفارش/لجر خراب.

## راه‌اندازی

```env
SUDO_IDS=123456789,987654321
WEBAPP_URL=https://your-host
```

سپس bootstrap برای جداول جدید:

```bash
python -m app.database.bootstrap <TELEGRAM_USER_ID>
```
