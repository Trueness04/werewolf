## ترتیب حل شب (اولویت واقعی CheckNight)

ترتیب اجرا در پایان تایمر شب (نه ترتیب کامنت قدیمی داخل فایل):

1. جوکر / هارلی → شوالیه → تیم گرگ (+ بتا/توله) → ببر → گرگ برفی  
2. قاتل → شیمیدان → بمبر → آتش‌نشان → مگنتو → کماندار → چیانگ → ومپایر  
3. **شکارچی فرقه** → فرقه → لوسیفر → عروس مرده → **فرشته** → ملکه یخی → لیلیس → عجوزه → کنت → فرانک → افسونگر → **فاحشه**  
4. گاو → هانتسمن → روح → موش → گرگ سفید → آگور → **پیشگو** → **احمق (گروهی)** → ققنوس → دزد → **نگاتیو** → جادوگر → دینامیت → هندوانه → خنیاگر  

نقش‌های روستا که در این زنجیره اثر مستقیم دارند با اولویت شب مشخص شده‌اند. نقش‌های صرفاً روز یا منفعل اولویت شب ندارند.

اثر انتخاب‌های شب تقریباً همیشه در `CheckNight` اعمال می‌شود (نه لحظهٔ کلیک)، مگر توانایی فوری روز مثل صلح / خواب‌گذار / حاکم / نقرهٔ آهنگر و شلیک مرگ کلانتر.

- `howToHoHome`، `HunterFindCultist`، `HunterKilledCultist`، `HunterFailedToFind`، `CultConvertCultHunter`، `CultHunterKilledCultVisit`، `HuntsmanDeadCultHulter`، …

### موارد خاص
- جاسوس او را خطرناک می‌بیند.
- شاهدخت نمی‌تواند او را زندانی کند (پیام فرار).
- تلهٔ هانتسمن / مجیک هیل تعامل دارند.
- Cult: مسیر ویژه کشتن مهاجم، نه تبدیل.

## ۲۷) role_Ruler — حاکم

### استدلال
یک‌بار اعلام حکومت می‌کند؛ در دور رأی بعد فقط او رأی می‌دهد و تایمر رأی کوتاه (`RulerSecendVote` = ۴۰ث) است.

### شناسنامه
| فیلد | مقدار |
|------|--------|
| تیم | rosta |
| نوع | فعال روز + کنترل رأی |
| اولویت شب | ندارد |
| وزن | ۴ |

### Workflow
1. روز: `RulerAsk` → `RulerNowRul` گروهی؛ `RulerOkAndUse`؛ `RulerOk = Day_no+1`؛ notSend.
2. فاز vote با RulerOk: فقط به حاکم howVote فرستاده می‌شود؛ تایمر ۴۰ث؛ خلاصهٔ وضعیت `RulerMessageVoteNow`.
3. اعدام با پیام `RulerKillPl` به‌جای killed_user عادی؛ پرچم `RulerOkSend`.
4. اگر رأی بی‌نتیجه: `RuleTimeEnd`.
5. مرگ حاکم قبل از اعمال رأی: `RulerIsDead` و لغو RulerOk.
6. پاک‌سازی RulerOk در night→day.

### کلید پیام
- `RulerAsk`، `RulerButton`، `RulerNowRul`، `RulerKillPl`، `RuleTimeEnd`، `RulerIsDead`، `RulerMessageVoteNow`

### موارد خاص
- شاهدخت حاکم را زندانی نمی‌کند.
- CultAttemp قطعی ۱.
- با صلح: اگر صلح فعال باشد SendVote کلاً نمی‌آید.

## ۲۸) role_Spy — جاسوس

### استدلال
روز چک می‌کند آیا هدف «نقش خطرناک/مسلح» است یا نه — بله/خیر، نه نام نقش.

### شناسنامه
| فیلد | مقدار |
|------|--------|
| تیم | rosta |
| نوع | فعال روز |
| اولویت شب | ندارد (CheckSpy بعد از کارآگاه) |
| وزن | ۵ |

### Workflow
1. روز: `SpyAsk` → انتخاب.
2. `CheckSpy`: اگر نقش در فهرست خطرناک → `SpySeeMessage`؛ وگرنه `SpySeeMessageNo`.
3. فهرست بله: گرگ‌های پایه، قاتل، کماندار، شکارچی، کلانتر، تفنگدار، آتش‌نشان، ملکه یخی، ومپایر، اصیل، شوالیه؛ ملکه جنگل فقط اگر AlphaDead.

### کلید پیام
- `SpyAsk`، `SpySeeMessage`، `SpySeeMessageNo`

### موارد خاص
- CultAttemp ≈ ۳۰٪ (مقاوم‌تر از متوسط روستا).
- Honey روی نتیجهٔ جاسوس اثر ندارد (نقش خام چک می‌شود).
