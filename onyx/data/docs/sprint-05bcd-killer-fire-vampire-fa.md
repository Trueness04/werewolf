# ۳. اسپرینت ۵ب — تیم قاتل

## ۳.۱ قاتل (`role_Qatel`) — وزن ۱۵

**شب:** کیبورد `AskKill`؛ خود و کماندار خارج از هدف. Resolve در `GetKiller`.

زنجیره: تله هانتسمن ۵۰٪ → زندان شاهدخت → شفای جادو → ققنوس → شاخه نقش:

| هدف | اثر |
|-----|-----|
| دلبر (تیم≠قاتل) | عشق؛ بدون قتل |
| دلبر (تیم=قاتل) | قتل عادی |
| شوالیه سیاه | عملاً مرگ قاتل |
| جوکر | CheckAttack سپس دفاع‌ها یا قتل |
| لیلیس | ۶۰٪ مرگ قاتل |
| اصیل قبل افشا | خانه خالی |
| کلانتر | قتل + HunterKill |
| پیش‌فرض | فرانک/مومیایی/سفید/فرشته بلاک یا قتل |

**دفاع وقتی روی قاتل حمله می‌شود:** گرگ ۸۰٪ مرگ گرگ؛ ومپایر/شکارچی مهاجم می‌میرد؛ فرقه دعوت‌کننده معمولاً می‌میرد؛ فرشته روی قاتل می‌میرد.

**مرگ قاتل →** اطلاع هیلدا. روز اکشن ندارد.

# ۴. اسپرینت ۵ج — تیم آتش

## ۴.۱ آتش‌نشان — وزن ۱۵

از روز≥۲: شب نفت‌پاشی به لیست (`FirefighterList`) بدون مرگ؛ با دکمه Fight همه لیست را می‌سوزاند مگر مجیک/سفید/فرشته/فرانک. بازدیدکنندگان خانه با هدف می‌سوزند. روز۱ بی‌اثر.

قفل برد: Fire یا Ice زنده بدون overpower → بازی ادامه.

## ۴.۲ ملکه یخ — وزن ۱۵

شب: اولین بار روی هدف → انجماد + NotSend شب بعد؛ بار دوم → مرگ. سفید/فرشته/فرانک بلاک. مرگ هر دو Fire+Ice → `DieFireAndIc` برای لیلیس.

## ۴.۳ لیلیس

قبل DieFireAndIc: فقط اگر هدف لوسیفر → کشف+کشت؛ وگرنه نیافت.  
بعد: کشت آزاد هر هدف.  
دفاع ۶۰٪ وقتی قاتل/کمان/ومپ/گرگ به او حمله کنند → مهاجم می‌میرد.

## ۴.۴ مگنتو

رأی تیمی مثل گرگ؛ ~۵۰٪ تبدیل هدف به Magento؛ وگرنه کشت (فرشته بلاک کشت). بالانس نیازمند IceQueen.

# ۵. اسپرینت ۵د — تیم ومپایر

## ۵.۱ ومپایر — وزن ۸

رأی تیمی شب. پیش‌دفاع: مجیک → ققنوس → فرانک.

پیش‌فرض اگر `VampireConvert` ست: رول گاز → `VampireBitten` (اسپرینت ۲).  
اگر گاز نشد و اصیل آزاد: قتل.  
وگرنه ۵۰٪ نوشیدن بدون مرگ یا قتل.

شاخه خاص: قاتل/شکارچی → مرگ ومپایر؛ گرگ پایه ۵۰٪ مرگ ومپایر؛ کلانتر بدون Convert → آزادسازی اصیل؛ لیلیس/سیاه شانس متقابل.

## ۵.۲ اصیل — وزن ۱۰

تا افشا کیبورد شب ندارد؛ خانه برای گرگ/قاتل خالی.  
افشا: ومپایر→کلانتر یا مرگ کلانتر → `Bloodthirsty` + `VampireFinded` + Convert≈۴۰.  
مرگ اصیل: DeadBloodthirsty + Convert≈۲۰ + فعال چیانگ.

## ۵.۳ چیانگ

قبل مرگ اصیل: هر شب یک دشمن تصادفی را «می‌فرستد» (اطلاع).  
بعد DeadBloodthirsty: عضو سطل ومپایر. alone → nothing.

## ۵.۴ کنت

شب: جاسوسی نقش‌های قدرتمند تا قبل Convert.  
وقتی همه ومپایر اکشن مردند: KentVampireConvert + کشت روزانه در DY.
