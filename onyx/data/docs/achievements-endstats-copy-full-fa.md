# کاتالوگ کامل کپی دستاورد و آمار پایان — لحن هیجانی

**لحن تأییدشده:** هیجانی / دراماتیک / انرژی شبِ آخر (گویندهٔ فینال)  
**نه بامزه، نه ریشخند روستا، نه پارافریز خشک.**

نمونهٔ مرجع تأییدشده:  
«چوبه بالا رفت… و برنده‌ی واقعی همان کسی بود که به دار کشیدید.»

**وضعیت:** فقط مستند — **Lang `.ini` و PHP دست نخورده.**  
منبع فعلی: `bot/Strong/Game_Mode/main_fa.ini` (دستاوردها) · `general_fa.ini` (برد/پایان)  
نمونهٔ اولیه: `docs/achievements-endstats-copy-samples-fa.md`

تاریخ: ۲۰۲۶-۰۸-۰۳

---

## قانون لحن

- جملهٔ کوتاه، سنگین، حس حکم نهایی / افشا
- معنی شرط دستاورد حفظ شود
- placeholderها (`{0}` `{1}` `{2}` …) دست نخورده بمانند
- بدون طنز نمکی / «نوش جان گله» / ریشخند گروه
