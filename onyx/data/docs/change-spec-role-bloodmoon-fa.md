# ۰. اصل حاکم

1. این نقش در سورس PHP / جدول نقش‌های فعلی وجود ندارد. پیاده‌سازی آینده لایهٔ «Delta» است، نه parity.

# ۰.۶ تحلیل جنس طراحی (ریشه)

| ریشه | نمونه | بلاد مون؟ |
|------|--------|-----------|
| **دارنشان‌گونه** — علامت → رویداد بعدی → تبدیل/جذب | دارنشان، دیان (مارک)، گاز معوق | **خیر** |
| **شب‌قفل / قفل سراسری شب** — یک اعلان زمان‌بندی‌شده → یک شب اکشن‌های رقیب می‌سوزد | نزدیک‌ترین: آهنگر (قفل کیبورد گرگ)، خواب‌گذار (قطع SendNight)، داوینا (قفل روز بعد) | **بله — همین** |
| مرگ‌محور / تبدیل فوری / فریب نقش | شکارچی، رویس، لوسیفر | خیر |

**جمع‌بندی ریشه:** این نقش از جنس **«اعلان روز → قفل سراسری شبِ بعد»** است، نه علامت/اعدام/بدل. برای خاندان ومپایر از نظر محصولی **قابل‌قبول** است (پنجرهٔ شکار یک‌شبه بدون افشای صریح تیم)، ولی با دارنشان **هم‌جنس نیست** و نباید در یک سطل مکانیکی با هم ادغام شود.

اگر محصول بعداً ریشهٔ دیگری بخواهد (فقط شب فوری بدون روز، فقط مرگ، فقط تبدیل، فقط فریب نقش)، باید از صفر با همان ریشه بازنویسی شود — **ولی این سند همچنان بلاد مون را دقیقاً مطابق مشخصات فعلی کامل می‌کند.**

الگوهای اجرایی نزدیک برای UI/زمان‌بندی: **آهنگر** (`AhangarOk = Night_no+1`) و **داوینا** (روز یک‌بار + اعلان گروه) — نه الگوی مارک دارنشان.

# ۱. تحلیل فاصله با ومپایر / شب فعلی

## ۱.۱ چه چیزی امروز هست

| مکانیک | رفتار PHP/اسپرینت |
|--------|-------------------|
| شکار ومپایر | رأی تیمی شب → `CheckVampire`؛ گاز معوق یا قتل (۵د) |
| حمله گرگ | `WolfTeam` (+ یخی/بتا/…) در CheckNight |
| قاتل | `GetKiller` |
| آتش | نفت / Fight آتش‌نشان (+ زنجیره مگنتو/یخ/لیلیس) |
| فرقه | `CheckCult` دعوت/تبدیل |
| قتل شب سیاه | عروس مردگان دیرشب (۵ه) |
| آهنگر | روز → نقره شب بعد؛ بلاک کیبورد خوردن گرگ |
| خواب‌گذار | روز → شب بعد بدون SendNight سراسری |
| داوینا | روز یک‌بار → روز بعد سکوت/بلاک نقش‌های روز |

## ۱.۲ چه چیزی این نقش اضافه می‌کند

یک‌بار در **فاز روز** اعلام می‌کند **شب بعد** خون‌ماه است. آن شب فقط سطل/تیم شکار ومپایر اثر کشت/گاز می‌دهد؛ حمله‌ها و اکشن‌های رقیب (گرگ، فرقه، قاتل، آتش، سیاه شب، و اکشن شب دفاعی/اطلاعاتی روستا) **می‌سوزند**. بعد از آن یک شب، قدرت تا ابد تمام است.

فایدهٔ برد: یک شب بدون فشار رقیب‌های کشت‌شب → ومپایر زنده می‌ماند و می‌تواند گرگ/فرقه را سریع‌تر به صفر (پیش‌شرط overpower ومپایر در اسپرینت ۴) نزدیک کند.

## ۱.۳ برخورد / هم‌پوشانی

| مقایسه | نتیجه |
|--------|--------|
| در برابر دارنشان | جنس جدا؛ بدون علامت/اعدام/تبدیل |
| در برابر آهنگر | هر دو روز→شب‌بعد؛ در خون‌ماه نقره هم «می‌سوزد» چون حمله گرگی برای سد شدن وجود ندارد (متن کاربر) |
| در برابر خواب‌گذار | خواب‌گذار همه را می‌خواباند؛ خون‌ماه باید ومپایر را بیدار نگه دارد — تعارض نیاز تصمیم (G-stack) |
| در برابر داوینا | داوینا روز را قفل می‌کند؛ خون‌ماه شب را — معمولاً مستقل |
| افشای گروه | بدون نام ومپایر، ولی تییز «یک جور درنده» نشت اطلاعاتی است |

# ۳. رفتار هدف — خلاصه یک‌صفحه‌ای

1. در فاز `day`، اگر هنوز استفاده نکرده و زنده است، کیبورد یک‌باره می‌گیرد.  
2. تأیید → قدرت مصرف می‌شود؛ فلگ `BloodMoonNight = Night_no + 1` (همان الگوی آهنگر)؛ PV به خود و هم‌خاندان؛ **گروه در روز لزوماً اعلان نمی‌کند** (اعلان گروه = شب خون‌ماه — §۹).  
3. شب هدف: فقط شکار خاندان ومپایر resolve می‌شود؛ فهرست سرکوب‌شده (§۵) می‌سوزد + پیام‌های سوخت.  
4. پایان همان شب (یا cleanup انتقال): فلگ شب پاک؛ `BeladMoonUsed` می‌ماند؛ دیگر هرگز کیبورد اعلان نمی‌آید.  
5. مرگ قبل از استفاده → PV مرگ اختصاصی؛ استفاده نشده → پیام پایان در صورت زنده ماندن تا آخر بدون اعلام.

# ۴. اکشن روز — UI / گیت / زمان‌بندی

## ۴.۱ گیت‌های ارسال کیبورد روز

هم‌الگوی `SendDayRole` (اسپرینت ۷): قبلاً در `SendDay`؛ `NotSend_{role}`؛ یخ روز؛ زندانی شاهدخت؛ `NotSendDay` (روز داوینا)؛ داج لوسیفر.

| مورد | مقدار |
|------|--------|
| متن پرس | `AskBeladMoon` — کانونیکال: «می‌خوای فردا شب رو ماه خونین ببینی؟ (یک‌بار)» |
| callback | `DaySelect_BeladMoon_Yes` / `_No` (یا یک دکمهٔ تأیید + انصراف؛ هم‌سبک آهنگر/داوینا) |
| شرط یک‌بار | `BeladMoonUsed` یا `NotSend_role_BeladMoon` پس از استفاده/ارسال موفق |
| فاز | فقط `day` — نه vote، نه night |
| اثر فوری کلیک بله | ست فلگ‌ها + PVها؛ نه کشت |

## ۴.۲ زمان‌بندی «فردا شب»

**پیشنهاد قفل‌شدهٔ مهندسی (تا خلاف آن):** هنگام تأیید در روز جاری:

- `BloodMoonNight = Night_no + 1`  
- `BeladMoonUsed = true`  
- `BeladMoonBy = uid` (اعلام‌کننده)

هم‌معنی آهنگر: بعد از شب N، در روز، `Night_no` هنوز N است → شب بعد N+1 خون‌ماه است.

| حالت لبه | رفتار پیشنهادی |
|----------|----------------|
| اعلام در روز۱ | شب۲ (= اولین `Night_no+1` پس از اعلام) خون‌ماه |
| مرگ اعلام‌کننده بعد از اعلام، قبل از شب | **خون‌ماه همچنان اجرا می‌شود** — قدرت مصرف شده؛ فلگ سراسری است نه وابسته به زنده بودن (پیشنهاد؛ G2) |
| اعلام سپس پایان بازی قبل از شب هدف | فلگ بی‌اثر؛ اگر «استفاده‌شده» باشد پیام unused نباید بیاید (G3) |
| دو بلاد مون | حداکثر ۱ در توزیع؛ اگر نه: فقط اولین اعلام معتبر؛ دومی `BeladMoonAlready` (G4) |

## ۴.۳ اعلان روز در گروه؟

**پیشنهاد:** در لحظهٔ کلیک روز **سکوت گروهی**؛ اعلان گروه فقط هنگام **ورود/شروع شب خون‌ماه** با متن کانونیکال (بدون نام ومپایر).  
علت: کاربر اعلان گروه را با حال شب سرخ داده؛ افشای زودهنگام روز، ده دقیقه بحث متا می‌سازد.  
**نیاز به تصمیم** اگر بخواهند همان روز هم تییز گروهی بدهند (G5).

## ۵.۴ ومپایر در خون‌ماه — چگونه شکار می‌کند

- `SendNight` برای سطل ومپایر (ومپایر، و پس از فلگ‌ها اصیل/چیانگ/کنت طبق ۵د) **فعال می‌ماند**.  
- Resolve همان `CheckVampire` / زنجیرهٔ گاز یا قتل اسپرینت ۵د.  
- دفاع‌های هدف که از اکشن شب روستا می‌آمدند (فرشته آن شب، …) سوخته‌اند → شکار ومپایر آن شب **آسان‌تر** از شب عادی است (نکته بالانس).  
- دفاع‌های **غیراکشن‌شب** روی کارت نقش (مثلاً شانس متقابل لیلیس اگر لیلیس هدف است ولی لیلیس خودش نسوخته به‌عنوان هدف؟ — اگر لیلیس اکشن نسوزانده ولی زنده است، شاخهٔ دفاعی وقتی ومپ به او می‌زند طبق جدول ۵د؛ G10).  
- بلاد مون **پیشنهاد: در رأی شکار تیمی شرکت می‌کند مثل عضو خاندان** مگر G1=خیر (فقط اعلان، بدون دندان).

## ۵.۵ چند ومپایر / چند بلاد مون

- چند ومپایر معمولی: یک رأی تیمی مثل همیشه؛ خون‌ماه فقط رقبا را قفل می‌کند.  
- چند بلاد مون: **پیشنهاد توزیع حداکثر ۱**؛ خون‌ماه سراسری است نه stacking چندشب.

## ۵.۶ تعامل آهنگر (کانونیکال)

اگر همان شب `AhangarOk == Night_no` و خون‌ماه فعال است:

- حمله گرگ از دو مسیر صفر است (نقره + سوخت خون‌ماه).  
- نقره از دید محصول «سوخته/بی‌اثر روایی» است چون چیزی برای سد شدن نبود.  
- PV آهنگر کانونیکال ارسال شود (§۹).  
- دستاورد نزدیک: شبیه `Wasted_Silver` با خواب‌گذار — **پیشنهاد:** همان دستاورد یا کلید جدید `Wasted_Silver_BloodMoon` (G11).

## ۵.۷ stacking با قفل‌های سراسری دیگر

| ترکیب | پیشنهاد |
|--------|---------|
| خون‌ماه + خواب‌گذار همان شب | **نیاز به تصمیم:** الف) خواب‌گذار برنده → حتی ومپ نمی‌کشد؛ ب) خون‌ماه استثنا می‌دهد به ومپ؛ ج) هر دو باطل و پیام تعارض. **توصیه بالانس: ب** |
| خون‌ماه + نقره | نقره روایی می‌سوزد؛ پیام آهنگر |
| خون‌ماه + داوینا | مستقل (روز/شب جدا) |
| خون‌ماه + NotSendNight شخصی | شخصی سر جایش؛ سراسری جدا |
