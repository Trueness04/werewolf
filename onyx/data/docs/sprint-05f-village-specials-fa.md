# اسپرینت ۵ف — نقش‌های ویژهٔ روستا (باقی‌مانده / عمق کامل)

**پیش‌نیاز:** اسپرینت ۱–۴ (شب، گاز، جفت‌نقش، داور برد) + اسپرینت ۵الف (فرقه/شکارچی) برای زنجیرهٔ هانتسمن←شکارچی  
**هدف:** اکشن کامل همهٔ نقش‌های `GetRoleTeam → rosta` که در این فهرست‌اند — هم‌ارز PHP بدون stub  
**مرجع سورس (اولویت):** `NG.php` / `DY.php` / `CM.php` / `HL.php` / `SE.php` (+ `VT.php` برای رأی، `join.php` برای فلگ شروع)  
**مرجع متقاطع (فرعی):** `docs/werewolf-python-rewrite-master-fa.md` §۸؛ اسناد قدیمی village/enemy اکنون stub ارجاع‌اند — در تعارض، PHP حاکم است  
**محدودیت سند:** بدون قطعه کد؛ متن فارسی؛ کلید Lang به‌جای متن ini؛ بدون Game_Mode

# ۱. تحلیل و استدلال

این بسته نقش‌هایی است که **تیم منطقی‌شان `rosta` است** ولی قدرت‌شان از «فقط پر کردن وزن روستا» فراتر می‌رود: قتل شب/روز، کنترل رأی، تبدیل، ماسک استعلام، محافظت، یا filler بالانس.

سه لایه جدا نگه دارید:

1. **شروع (`join`)** — مهمات/تله/فلگ کلانتر (`GunnerBult=2`، `HuntsmanT=2`، `SheriffBult=1`، `KalanInGame`)، لینک‌های فراماسون/پیشگو/ناظر.  
2. **اکشن فاز** — انتخاب در Redis (`Selected` / کال‌بک‌های فوری روز)؛ اثر در `CheckNight` / `CheckDay` / `VT` / کال‌بک فوری CM.  
3. **مرگ (`UserDead`)** — زنجیره‌های عاشق، پیش‌رزرو، خائن، وحشی، هانتسمن←شکارچی، سپر ققنوس، زندان شاهدخت، پاک‌سازی نگهبانی.

نکتهٔ معماری حیاتی: اکثر اکشن‌های شب **در لحظهٔ کلیک اثر نمی‌کنند**؛ در پایان تایمر `CheckNight` با ترتیب ثابت حل می‌شوند. استثناهای فوری روز: صلح، خواب‌گذار، آهنگر، حاکم، کدخدا، دردسرساز، گیاه‌شناس (تأیید گاز)، شلیک مرگ کلانتر.

نقش‌هایی که در بعضی لیست‌های مود کامنت شده‌اند (`role_Cow`، `role_Botanist`، `role_Mouse`/`Watermelon` در برخی شاخه‌ها) همچنان **resolver کامل در NG/CM/SE دارند**؛ برای پورت باید وجود اسکلت و gate مود را جدا از منطق resolver ثبت کنید.

# ۳. ترتیب حل مرتبط

## ۳.۱ شب (`NG::CheckNight`) — نقاط روستا

ترتیب واقعی (خلاصهٔ مرتبط با روستا؛ لیست کامل دشمن در مستند دشمن/۵ه):

1. جوکر / هارلی  
2. **شوالیه** (`CheckKnight`)  
3. تیم گرگ (+ توله/بتا؛ ممکن است وقفه)  
4. **ببر** → گرگ یخی → قاتل (ممکن است `HunterKill` و قطع ادامه)  
5. **شیمیدان** → بمبر → آتش → مگنتو → کماندار → چیانگ → ومپایر  
6. **شکارچی فرقه** → فرقه → لوسیفر شب‌صفر → عروس  
7. **فرشته** → یخ/لیلیس/عجوزه/کنت/فرانک/افسونگر → **فاحشه**  
8. **گاو** → **هانتسمن** → **روح** → **موش** → گرگ سفید → **فالگیر** → **پیشگو** → **احمق گروهی** → **ققنوس** → دزد → **نگاتیو** → جادوگر → دینامیت → **هندوانه** → خنیاگر  

اثر نگهبانی فرشته و تلهٔ هانتسمن و سپر ققنوس **قبل از حل نهایی فرشته/هانتسمن** در حملات زودتر خوانده می‌شود (کلید از لحظهٔ انتخاب یا شب‌های زوج ققنوس).

## ۳.۲ روز (`DY::CheckDay`)

1. **تفنگدار** — اگر `HunterKill` ست شود، ادامهٔ روز قطع می‌شود  
2. شوالیه سیاه / دینامیت (غیرروستا)  
3. **کارآگاه**  
4. **جاسوس**  
5. **شاهدخت** (فقط وقتی `Night_no > 2`)  
6. دیان / کنت (غیرروستا)

صلح / کدخدا / حاکم / آهنگر / خواب‌گذار / دردسرساز اثر فوری در کال‌بک روز دارند، نه داخل `CheckDay`.

## ۳.۳ رأی (`VT` + CM)

ترتیب مفهومی: صلح (لغو) → حکومت (فقط حاکم) → شمارش (کدخدا دوبل، پسر گیج ۵۰٪ منحرفی) → شاهزاده یک‌بار نجات → اعدام → اگر کلانتر `HunterKill` با `vote`.

دردسرساز: پس از حل رأی اول، اگر `trouble` ست باشد `TroubleVote` اجرا و فاز رأی دوم بدون شب می‌ماند (`trouble:ok`).

### گاز گرگ (داخل WolfTeam)
1. فرشته روی او → نجات عادی.  
2. شانس شلیک = `HunterKillWolfChanceBase` (۳۰) + ۲۰×(تعدادگرگ−۱).  
3. موفق + ۱ گرگ: گرگ با `shot` می‌میرد؛ کلانتر زنده؛ پیام‌های `HunterShotWolf*`.  
4. موفق + چند گرگ: یک گرگ shot + خود کلانتر eat (**بدون** منوی HunterKill مرگ).  
5. ناموفق: مسیر گاز عادی (گاز گرفتن آلفا/… یا مرگ).

### شلیک مرگ (`HL::HunterKill`)
فعال وقتی مرگ از: **رأی** (`vote`)، **شلیک تفنگدار** (`shot`)، **مرگ عاشقانه/kill** مرتبط. گاز سادهٔ شب معمولاً منو نمی‌دهد.

جریان:
1. ست `HunterKill` + `KillFor`؛ +۴۵ث تایمر؛ ارسال پیام گروهی فوری.  
2. PV: `HunterShotChoice` یا `HunterLynchedChoice` + کیبورد `Kalantar_shot`.  
3. انتخاب هدف (`KalanShot`) یا `Skip` در CM (کلانتر حتی اگر `in_game` خاص).  
4. حل نهایی کرون با کلیدهای شلیک نهایی (`HunterKilledFinalShot` / `HunterKilledFinalLynched`).
