# اسپرینت ۱ — پایپ‌لاین کامل شب (اجرایی)

**وضعیت:** پذیرفته‌شده به‌عنوان نقطهٔ شروع بازنویسی پایتون  
**هدف اسپرینت:** رفتار شب هم‌ارز PHP برای اسکلت resolve — نه لزوماً همهٔ نقش‌های فرعی با جزئیات کامل  
**خروجی قابل قبول:** انتخاب شب ذخیره می‌شود؛ پایان تایمر با ترتیب ثابت حل می‌شود؛ وقفه‌ها روز را عقب می‌اندازند؛ دفاع مشترک گرگ/قاتل درست است؛ فلگ گاز ست می‌شود (اعمال تبدیل = اسپرینت ۲)  
**مرجع سورس:** `NG.php`, `HL.php`, `CM.php` (ست فلگ روز)  
**مرجع کلان:** `docs/werewolf-python-rewrite-master-fa.md`

---

# ۱. تحلیل و استدلال

بدون اسکلت شب، هر نقش جداگانه بعداً دوباره به زنجیره دفاع و وقفه‌ها وصل می‌شود. PHP انتخاب را در طول شب ذخیره می‌کند و اثر را فقط در `CheckNight` می‌دهد؛ سه وقفه (توله، کلانتر، رویس) می‌توانند انتقال به روز را نگه دارند. کامنت بالای تابع CheckNight با ترتیب واقعی کد هم‌خوان نیست — جدول این سند مرجع است.

اسپرینت ۱ عمداً **تبدیل قطعی گاز** و **بردهای خاص** را کامل نمی‌کند؛ فقط فلگ‌های گاز را همان‌طور که PHP ست می‌کند ثبت می‌کند تا اسپرینت ۲ (`BittanCheck`) روی همان قرارداد سوار شود.

# ۲. محدوده اسپرینت (In / Out)

## داخل محدوده

- ارسال کیبورد شب + گیت‌های skip
- ترتیب کامل `CheckNight` (همهٔ اسلات‌ها؛ نقش‌های فرعی می‌توانند stub با «انتخاب ذخیره + no-op یا kill ساده» داشته باشند تا ترتیب حفظ شود)
- پایپ‌لاین کامل خوردن گرگ (`WolfTeam`) با دفاع و bite/eat
- پایپ‌لاین کامل قاتل (`GetKiller`) با دفاع
- وقفه‌های توله (+۴۵ثانیه)، کلانتر (`HunterKill`)، رویس (+۳۰ثانیه)
- early-end شب (نصف تایمر + همه انتخاب کرده‌اند)
- cleanup انتهای شب
- انتقال night→day فقط وقتی وقفه نباشد

## خارج از محدوده (اسپرینت‌های بعدی)

- اعمال تبدیل گاز در پایان رأی (`BittanCheck`) — اسپرینت ۲
- جفت‌نقش کانفیگ/UserRole — اسپرینت ۳
- `CheckEndGame` کامل — اسپرینت ۴
- پیاده‌سازی عمیق همهٔ نقش‌های فرعی (فرقه، ومپایر، آتش، سیاه، جوکر، …) — اسپرینت ۵+
- بانک کامل پیام / nightclub — موازی یا آخر

**قانون stub:** اگر نقش در اسلات CheckNight است ولی هنوز عمیق نشده، تابع اسلات باید وجود داشته باشد و ترتیب را نشکند؛ ترجیحاً فقط در صورت انتخاب، اثر حداقلی یا no-op مستند کند — جابه‌جا کردن اسلات ممنوع است.

# ۳. جریان ورود شب

1. Handler اگر `game_state == night` → `NG.Handel`
2. اگر `GamePl:KhabgozarOk` فعال → **خروج کامل** (بدون کیبورد)
3. `SendNightRole` → `ElamShekar` → قفل `NightRoleSends` → `CheckLucifer`
4. در طول فاز: کال‌بک‌ها فقط `Selected:*` می‌نویسند
5. `checkTime`: اگر باقیمانده ≤ نصف `night_timer` و همه گیرندگان انتخاب کرده و `MessageNightSend` خالی → `timer = now - 5`
6. `CheckTimer` وقتی `timer` تمام: `CheckNight`؛ در نبود وقفه → `ChangeGameStatus('day')`

هنگام ورود به شب (`ChangeGameStatus('night')`): اگر خواب‌گذار → `timer = 0`.

# ۴. گیت‌های ارسال کیبورد (`SendNightRole`)

برای هر بازیکن زنده، به ترتیب:

1. قبلاً در `SendNight` یا `NotSend_{role}` → رد
2. یخ‌زده با `(iced_night + 1) == Night_no` → رد
3. زندانی شاهدخت → رد
4. `NotSendNight == Night_no` → رد همه
5. `NotSend:{uid} == Night_no` → رد

### گیت نقش‌محور (اجباری در اسپرینت ۱ برای گرگ/قاتل/کلیدی‌ها)

| نقش | skip اگر |
|-----|----------|
| گرگ‌های خورنده | `MastEat` یا `AhangarOk` |
| ملکه جنگل | آلفا نمرده یا Mast/Ahangar |
| گرگ یخی | Mast یا Ahangar |
| گرگ سفید | هیچ گرگ پایه‌ای زنده نباشد (شرط ارسال جدا) |
| ققنوس | شب غیر از ۲ و ۴ |
| هارلی | جوکر نمرده |
| اصیل / چیانگ / مومیایی / روح / خنیاگر / کماندار / هانتسمن | فلگ فعال‌سازی مربوطه |

الهه / همزاد / وحشی: پس از ارسال یک‌بار، `NotSend_role_*` تا دوباره نگیرند.

# ۶. وقفه‌ها

## ۶.۱ مرگ توله (`WolfCubeDead`)

**ست:** مرگ نقش توله با علت ≠ afked → `WolfCubeDead = Night_no + 1`

**در CheckNight همان شب فلگ:**
1. بستن کیبوردها
2. `PlusTime(+45)`
3. Unlock تیم گرگ (حذف از SendNight + پاک انتخاب‌های گرگ)
4. `SendWolfCubeDead = true`
5. پاک `CheckNight` و `SendNightAll`
6. return false

**شروع WolfTeam در شب بازشده:** اگر همان شب و SendWolfCubeDead → پاک فلگ‌های توله و آماده‌سازی resolve دوم.

## ۶.۲ کلانتر (`HunterKill`)

بعد از GetKiller اگر فلگ باشد → return false.  
تایمر تا شلیک/اسکیپ کلانتر جلو نمی‌رود به روز.  
ست معمولاً وقتی هدف حمله کلانتر است یا مرگ کلانتر شات می‌خواهد: +۴۵ثانیه، کیبورد شلیک.

## ۶.۳ رویس (`RoyceDead`)

ست: مرگ رویس → `RoyceDead = Night_no + 1`  
در انتهای CheckNight: بستن کیبورد، `RoyceSelectd2=true`, پاک Selected، +۳۰ثانیه، باز کردن انتخاب فرقه، پاک CheckNight/SendNightAll.  
CheckNight همچنان true برمی‌گرداند؛ جلوگیری از روز با `RoyceSelectd2` در تایمر است.

## ۶.۴ StopBlack

در سورس فعلی stub/مرده است؛ در پایتون هم فقط گیت خواندن کافی است مگر منبع ست پیدا شود.

# ۷. دفاع خوردن گرگ (`WolfTeam`) — اجباری کامل

### پیش‌نیاز
- تیم گرگ زنده
- چندگرگ: رأی `Selected:Wolf:*` → بیشینه؛ تک: `Selected:{uid}`
- هدف زنده؛ سپس پاک رأی تیمی

### دفاع مشترک قبل از شاخه نقش (ترتیب ثابت)

1. تله هانتسمن — ۵۰٪ → مرگ آخرین گرگ انتخاب‌کننده  
2. شفای جادویی  
3. ققنوس (`PhoenixHealer:{uid}`)  
4. نگهبان فرانک (`role_franc:AngelIn`)  
5. زندان شاهدخت  

هر کدام موفق → حمله تمام (بدون eat)، پیام‌های مربوطه.

### پس از دفاع: شاخه نقش هدف

حداقل باید پیاده شود:

| هدف | رفتار |
|-----|--------|
| نفرین‌شده | زنده + تبدیل به گرگینه + NotSend همان شب |
| مست | مسیر eat + `MastEat = Night_no+1` |
| ریش‌سفید | بار اول زخم بدون مرگ (`Eatelder`)؛ بار بعد eat |
| قاتل | ۸۰٪ مرگ آخرین گرگ؛ وگرنه ادامه |
| کلانتر | شانس شات `30 + (wolves-1)*20` ممکن است HunterKill؛ وگرنه ادامه |
| Blood مخفی | خانه خالی؛ افشاشده ۴۰٪ کشتار گرگ |
| default و اکثر نقش‌ها | الگوی bite سپس eat |

### ترتیب bite قبل از eat (الگوی غالب)

فرشته (اگر در شاخه باشد) → افسونگر (`Enchanter_Conver` ۳۰٪) → ملکه جنگل (`forestQueen_Convert` ۱۰٪) → آلفا (`alpha_convert` ۲۰٪) → **eat**

Bite موفق فقط فلگ می‌گذارد:
- `BittanPlayer` یا معادل افسونگر  
تبدیل نقش = اسپرینت ۲ (`BittanCheck` در انتقال vote→night).

# ۸. دفاع قاتل (`GetKiller`) — اجباری کامل

پیش‌شرط: قاتل زنده + انتخاب + هدف زنده

1. تله هانتسمن ۵۰٪  
2. زندان شاهدخت  
3. شفای جادویی  
4. ققنوس  
5. شاخه نقش:
   - دلبر: عشق یا مسیر قتل  
   - شوالیه سیاه: عملاً مرگ قاتل  
   - default: فرانک → مومیایی → گرگ سفید → فرشته → لیلیس ۶۰٪ → Blood مخفی → kill  
   - اگر هدف کلانتر → ممکن است `HunterKill`

# ۱۵. محتوای یکتا منتقل‌شده — تیم گرگ (از `werewolf-roles-complete-reference-fa.md`)

> روایت فشردهٔ لبهٔ نقش‌های گرگ که در جدول master §۸ خلاصه‌تر بود. پایپ‌لاین خوردن همین سند (§ مربوط به WolfTeam) مرجع resolve است؛ جزئیات نقش عمیق‌تر در اسپرینت‌های بعدی یا master. در تعارض، PHP حاکم است.

### مفهوم خورنده در برابر غیرخورنده

خورنده شب: توله، گرگینه، گرگ‌ماه، آلفا، و ملکه پس از فعال‌سازی. رأی تیمی اکثریت روی یک هدف؛ تکنفره مستقیم. غیرخورنده: جادوگر، عجوزه، افسونگر، سفید، بتا، یخی — تیم Mongo گرگ دارند ولی در رأی خوردن نیستند تا تبدیل شوند.

رأی تیمی: هر رأی‌دهنده یک واحد به لیست هدف؛ بیشینه؛ در تساوی اولین پس از مرتب‌سازی نزولی؛ مهاجم رسمی آخرین تغییر نقش بین خورنده‌ها.

بلاک کیبورد خوردن وقتی مست یا نقره برای شب جاری فعال است برای خورنده‌ها و ملکه فعال و یخی.

اولویت گاز در حمله موفق: افسونگر ۳۰٪ سپس ملکه ۱۰٪ سپس آلفا ۲۰٪ سپس خوردن.
