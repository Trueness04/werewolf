# اسپرینت ۳ — جفت‌نقش‌ها و تبدیل‌های اجباری

**پیش‌نیاز:** اسپرینت ۱–۲ (شب و گاز پایدار)  
**هدف:** کانفیگ وابسته + تزریق/تبدیل قبل از بالانس + تبدیل‌های runtime غیرگاز  
**مرجع:** `GR::ChangeConfig`, `join::UserRole`, `HL::UserDead` / `ConvertPlayer`

---

# ۱. تحلیل و استدلال

سه لایه جدا که نباید قاطی شوند:

1. **کانفیگ گروه** — روشن/خاموش کردن نقش‌ها قبل از بازی؛ جفت‌ها را همگام می‌کند تا تنظیم غیرقابل‌بازی نماند.  
2. **پیش‌بالانس** — بعد از ساخت استخر و قبل از قبول دست؛ نقش‌های ناقص جفت را اجباری پر/عوض می‌کند.  
3. **Runtime** — در طول بازی با مرگ یا رویداد؛ نقش یا فلگ فعال‌سازی عوض می‌شود (جدا از گاز اسپرینت ۲).

اشتباه رایج: فعال‌سازی ملکه جنگل یا افشای اصیل را «تبدیل نقش» دانستن — نقش همان است؛ فقط فلگ اکشن عوض می‌شود.

---

# ۲. محدوده

## داخل
- همه همگام‌سازی‌های ChangeConfig
- گیت وابسته به گرگ پایه
- تبدیل‌های اجباری A–I در UserRole
- گاردهای جفت در بالانس (رد دست)
- تبدیل‌های runtime جدول زیر (غیرگاز)

## خارج
- گاز تأخیری (اسپرینت ۲ — تغییر نکند)
- CheckEndGame کامل (اسپرینت ۴)
- عمق اکشن همه نقش‌های تبدیل‌شده (اسپرینت ۵+)

# ۳. جفت‌های کانفیگ

| تغییر | اثر |
|-------|-----|
| Vampire ↔ Bloodthirsty | همیشه هم‌مقدار |
| kalantar = off | هر دو vamp off |
| ferqe ↔ shekar ↔ Royce | سه‌تایی؛ Royce=on جفت را on می‌کند؛ Royce=off لزوماً بقیه را خاموش نمی‌کند |
| IceQueen ↔ Firefighter | دوطرفه |
| Qatel = off | Archer off |
| Archer = on | Qatel on |

گرگ پایه = Alpha / Tolle / Wolfx / Gorgine.  
نقش‌های وابسته (Jadogar, Honey, enchanter, WhiteWolf, forestQueen, Khaen, NefrinShode): بدون حداقل یک گرگ پایه → off اجباری یا رد با پیام.

# ۵. تبدیل / فعال‌سازی runtime (غیرگاز)

| تریگر | اثر |
|-------|-----|
| مرگ الگوی وحشی | وحشی → گرگینه |
| مرگ هدف همزاد | همزاد → نقش قربانی (شاخه‌های ویژه تیم) |
| مرگ پیشگو | رزرو → پیشگو |
| آخرین گرگ مرد | خائن و/یا سفید → گرگینه |
| مرگ آلفا | فعال ملکه: AlphaDead + forestQueenBitten (نقش ثابت) |
| مرگ شکارچی | هانتسمن → شکارچی |
| مرگ/مسیر کلانتر قبل افشا | اصیل لو می‌رود؛ VampireConvert≈۴۰ (نقش ثابت) |
| مرگ اصیل | VampireConvert≈۲۰؛ فلگ‌های پس از مرگ |
| نفرین‌شده خورده | فوری → گرگینه (نه فردا) |
| فرقه موفق | هدف → ferqe |
| Magento موفق ~۵۰٪ | هدف → Magento |
| تیر به ریش‌سفید (کلانتر/تفنگدار/شیمیدان) | مهاجم → روستایی |
| عسل | فقط فریب دید؛ نقش عوض نشود |

`ConvertPlayer` همیشه: Mongo نقش+تیم، Redis کش، change_time، و سایدافکت‌های نقش مبدأ (مثلاً ClearEnchanter، زنجیره رزرو، لو Blood از کلانتر).
